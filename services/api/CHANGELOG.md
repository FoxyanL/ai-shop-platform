# Журнал изменений API

## 0.1.0

- Создан API на Koa и TypeScript с документацией OpenAPI/Swagger.
- Добавлены OTP-регистрация и вход, роли, access-токены и HttpOnly refresh-cookie.
- Реализованы CRUD-модули пользователей, новостей, брендов, размеров, категорий, товаров, оплаты и доставки.
- Добавлены магазины, публичная витрина, получатели, корзина, чекаут и транзакции.
- Созданы PostgreSQL-миграция, Redis-хранилище сессий и публикация событий в Streams.
- Добавлены интеграционные проверки с порогом покрытия API не ниже 80% по строкам и операторам.
