# SaaS-конструктор интернет-магазинов с ИИ-помощником

Облачная платформа, в которой предприниматель без навыков программирования создаёт интернет-магазин, выбирает шаблон, редактирует страницы и публикует витрину. Панель каталога и заказов обслуживает созданные в конструкторе магазины.

## Цель текущего этапа

Итерация 1 — интерактивный прототип конструктора: пошаговое создание магазина, выбор шаблона, редактирование главной страницы и живой предпросмотр. Полный план — в [дорожной карте](docs/roadmap.md).

## Разработка

На текущем этапе используются HTML, CSS и JavaScript без сборки. Настройки магазинов сохраняются в локальном хранилище браузера. Аккаунтов, серверной изоляции, реальной оплаты, доставки и подключения языковой модели пока нет.

### Запуск

Откройте `index.html` в браузере или запустите локальный сервер из папки проекта:

```powershell
python -m http.server 8025
```

Затем перейдите на `http://localhost:8025`.
