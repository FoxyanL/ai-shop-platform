# SaaS-конструктор интернет-магазинов с ИИ-помощником

Облачная платформа, в которой предприниматель без навыков программирования создаёт интернет-магазин, выбирает шаблон, редактирует страницы и публикует витрину. Панель каталога и заказов обслуживает созданные в конструкторе магазины.

## Текущий этап

Итерация 2 — серверная основа: аккаунты, вход и хранение магазинов в SQLite с проверкой владельца при каждом изменении. Подробный план и критерии — в [дорожной карте](docs/roadmap.md).

## Разработка

Интерфейс работает на HTML, CSS и JavaScript без сборки. Сервер использует стандартную библиотеку Python и SQLite, внешние пакеты не нужны. При регистрации можно перенести магазины из старого локального прототипа. Пароли хранятся в виде производных хэшей, сессии — в защищённых от JavaScript cookie.

Это учебная локальная версия, не готовая к публикации в интернете. Для промышленного размещения понадобятся HTTPS, настройка безопасной cookie, резервное копирование, управление секретами, миграции базы и отдельная проверка безопасности.

### Запуск

Запустите сервер из папки проекта:

```powershell
python server.py
```

Откройте `http://127.0.0.1:8025`. При необходимости порт можно изменить переменной `SHOP_PORT`.
