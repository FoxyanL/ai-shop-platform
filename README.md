# SaaS-платформа для создания интернет-магазинов с ИИ-помощником

Учебный проект по разработке облачной платформы, позволяющей создавать и развивать интернет-магазины без навыков программирования.

## Цель текущего этапа

Постепенно собрать рабочий MVP: сначала уточнить требования и архитектурные решения, затем реализовать регистрацию и рабочие пространства магазинов, каталог и витрину, заказы и ИИ-помощника. Интеграции с оплатой и доставкой добавлять после того, как будет готов основной пользовательский сценарий.

## Разработка

Технологический стек и структура приложения будут зафиксированы отдельным небольшим этапом после согласования базовых требований. Каждый этап должен оставлять проект в понятном, проверяемом состоянии. Комментарии в исходном коде и документация ведутся на русском языке.
