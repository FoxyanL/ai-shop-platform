# План разработки

План ориентировочный; этапы будем уточнять по мере реализации.

1. **Этап 1 — демонстрационный фронтенд** — готовый интерфейс владельца, каталог, заказы, витрина и имитация ИИ-помощника. Данные сохраняются в браузере; серверных учетных записей и внешних интеграций нет.
2. **Этап 2 — рабочее приложение** — выбрать и зафиксировать стек, добавить серверную часть, базу данных, учетные записи, роли, изоляцию магазинов и настоящие сценарии каталога и заказа.
3. **Этап 3 — запуск и интеграции** — подключить ИИ-модель, платежи и доставку, подготовить развертывание, документацию и приемочные испытания.

Переход к следующему этапу делаем после обсуждения результата и уточнения требований.

Каждый этап разбивается на небольшие изменения и коммиты. Не публиковать секреты и ключи API в репозитории.
