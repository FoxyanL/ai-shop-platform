# План разработки

План ориентировочный; этапы будем уточнять по мере реализации.

1. **Уточнение MVP** — зафиксировать сценарии, ограничения, стек и базовую архитектуру.
2. **Каркас приложения** — структура кода, локальный запуск, конфигурация и проверка качества.
3. **Учетные записи и магазины** — вход, создание магазина, роли и изоляция данных.
4. **Каталог и витрина** — управление товарами и публичное отображение.
5. **Корзина и заказы** — оформление и рабочее место менеджера.
6. **ИИ-помощник** — генерация черновиков с безопасной обработкой ошибок.
7. **Интеграции** — платежный провайдер и доставка в тестовом режиме.
8. **Подготовка к демонстрации** — документация, приемочные сценарии и развертывание учебной версии.

Каждый этап разбивается на небольшие изменения и коммиты. Не публиковать секреты и ключи API в репозитории.
